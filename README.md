# nutrient-uptake-in-vivo

The repository includes the code for the paper from Wang et al.

## System requirements
All code requires a computer with RAM 16+GB to run and store the statistical results.

Setting up the environment
Install R version 4.5.3

Download the following R packages:

'uwot' version 0.2.4
'lmme4' version 2.0-1
'effects' version 4.2-5
